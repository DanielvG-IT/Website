## What it is

A personal finance platform concept exploring how income, expenses, investments,
savings, and net worth can be unified into a single honest financial view.

## Why it was built

Financial software requires careful domain design before implementation. This
project is currently focused on mapping out the data architecture and domain
model rather than rushing to build features.
